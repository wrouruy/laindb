## Installation

<blockquote>
  <details>
    <summary><strong>Requirements</strong></summary>
    <ul>
      <li>GCC 10+</li>
      <li>C++ 17</li>
      <li>Standalone Asio (header-only)</li>
    </ul>
  </details>
</blockquote>

1. clone source code:
```bash
git clone https://github.com/wrouruy/darko.db.git && cd darko.db
```
2. compile:
```bash
make
```
